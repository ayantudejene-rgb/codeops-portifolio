# Day 12 — HTML Forms, Tables, Media & Accessibility

## How to open
Open `index.html` in a web browser, then use the navigation links to switch between Reservations and Contact.

## Exercises
1. Ethio Telecom registration form
2. Ethiopian Airlines five-row flight table
3. Accessible media block
4. Accessibility fixes
5. Complete accessible head

## Accessibility features
- Semantic landmarks
- One h1 per page
- Real labels for form controls
- HTML validation
- Keyboard-accessible native controls
- Meaningful image alt text
- Figure and figcaption
- Table captions and scope headers
- Titled map iframe
- Unique titles and meta descriptions
